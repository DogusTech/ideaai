# TogetLink IdeaAI — Microsoft Store listing (0.1.7)

## Description

TogetLink IdeaAI is an autonomous AI desktop engineering workspace for developers, technical teams, and junior engineers who want practical help building and shipping software.

IdeaAI works locally with your desktop workspace, terminal, files, Git branches, and development tools. When you close your laptop, work can continue through the cloud control plane for connected repositories and services. IdeaAI can inspect issues, run tests, explain failures, prepare code changes, and keep an overnight engineering task moving until you are ready to review it.

IdeaAI is also a technical mentor. It explains what it is doing, why a change is needed, which files were inspected, what commands were run, how tests behaved, and what remains unresolved. Junior developers can follow the reasoning, review focused diffs, and learn the workflow instead of receiving an unexplained block of generated code.

Use IdeaAI to:

- Work directly with local files, folders, terminal commands, and Git workflows.
- Continue eligible engineering tasks in the cloud while your computer is asleep or turned off.
- Investigate bugs, refactor code, add features, and run verification steps.
- Review View, Edit, Create, Delete, Search, Thought, and terminal activity in a structured timeline.
- Receive clear technical summaries and morning progress briefs.
- Keep sensitive local work on-device when local execution is the right choice.
- Connect cloud repositories and services when overnight execution is required.

IdeaAI is designed to keep the engineer in control: inspect the plan, review the evidence, understand the diff, and decide what ships.

## What's new in this version

Version 0.1.7 introduces the first major IdeaAI workspace refresh and strengthens the foundation for local and overnight engineering workflows:

- Reworked the desktop workspace interface with a cleaner, quieter layout and a more focused conversation flow.
- Added the new IdeaAI identity and updated the application, authentication, and workspace logo surfaces.
- Added structured activity visibility for file views, edits, creates, deletes, searches, thoughts, terminal commands, and line-level change summaries.
- Improved the experience for junior developers with clearer technical explanations, visible execution steps, and reviewable diffs instead of dumping generated code into the conversation.
- Added persistent conversation and project history so users can return to their own workspaces and recent tasks.
- Added sidebar collapse behavior, workspace controls, settings, browser preferences, skill toggles, and desktop completion notifications.
- Added authentication improvements for email/password, email verification codes, Google, and GitHub sign-in flows.
- Added the foundation for Railway-backed cloud execution and overnight repository workflows.
- Improved local execution routing and error messages for the desktop/Ollama development path.
- Updated the Windows desktop package to version 0.1.7.
